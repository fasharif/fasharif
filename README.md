I build web applications end to end, from the database design and API to the screens people use.

My main project, **[TopFlow Hub](https://github.com/fasharif/topflow)**, is an online store and
trade portal built around the real catalogue of Top Flow, a UAE irrigation supplier (used with
their permission). It is about 40,000 lines of TypeScript: a storefront, a trade portal with
quotations and purchase approvals, a staff back office, a REST API and a mobile app, all sharing
one set of business rules.

My low-level background comes from 42 Abu Dhabi's C curriculum. Those projects now have automated
tests and CI, including sanitizer builds that found several memory bugs, since fixed.
